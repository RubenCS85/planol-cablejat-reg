# Plànol de cablejat del quadre de reg (R4)

Plànol interactiu del quadre: Raspberry Pi 3B, watchdog ZIEHL WD100V, contactor K0 i mòdul de relés Waveshare, amb 4 sectors ampliables a 8.

Pàgina: https://rubencs85.github.io/planol-cablejat-reg/

- `plano-cableado-r4.html`: la pàgina.
- `fotos/`: fotos dels equips. Després de canviar-ne o afegir-ne una, executa `python fotos/incrusta.py`. El script les incrusta a la pàgina i torna a generar `index.html`.

Les connexions segueixen la memòria R4 del 17/11/2026. El costat de cada born és orientatiu: mira l'etiqueta de cada equip. La part de 230 V i els calibres els decidix l'instal·lador. Les fotos són de catàleg, i algunes només són d'exemple.
